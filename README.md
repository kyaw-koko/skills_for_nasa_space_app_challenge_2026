# SPHEREx SkyShift — Planet X & SPHEREx Explorer (NASA Space Apps Challenge 2026)

An interactive web visualization and data-exploration platform built for the **2026 NASA Space Apps Challenge** (*Planet X & SPHEREx* challenge). **SPHEREx SkyShift** processes near-infrared spectral data from NASA's SPHEREx mission (102 spectral bands) and pairs it with localized Myanmar-language explanations to make live astronomical data accessible to students, educators, and citizen scientists.
